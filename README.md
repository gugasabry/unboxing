<h1 align="center">📦 Projeto Unboxing</h1>

<h4 align="center">
Transformando TV Boxes apreendidas em computadores educacionais com Linux.
</h4>

<p align="justify">
O projeto <b>Unboxing</b> vem sendo desenvolvido no <b>Instituto Federal da Paraíba (IFPB)</b> desde Fevereiro de 2025, sob orientação do docente <a href="http://lattes.cnpq.br/1391293610402784" target="_blank">Gustavo Sabry</a>.
</p>

<p align="justify">
A iniciativa tem como objetivo resignificar receptores digitais apreendidos pela Receita Federal do Brasil, transformando equipamentos originalmente utilizados de forma ilegal em minicomputadores educacionais funcionais.
</p>

<p align="justify">
Após o processo de descaracterização, as TV Boxes passam a executar distribuições Linux customizadas do sistema <b>Unboxing</b>, possibilitando sua utilização em atividades de:
</p>

<ul>
  <li>Inclusão digital;</li>
  <li>Ensino de programação;</li>
  <li>Educação maker;</li>
  <li>Robótica educacional;</li>
  <li>Servidores Linux;</li>
  <li>Pesquisa científica;</li>
  <li>Laboratórios de informática de baixo custo.</li>
</ul>

# 📦 <a id="objetivo"/>Objetivo do Projeto

O projeto Unboxing busca:

- Reduzir lixo eletrônico;
- Promover sustentabilidade ambiental;
- Reutilizar equipamentos apreendidos;
- Democratizar o acesso à computação;
- Incentivar pesquisa científica;
- Ofertar inclusão digital para comunidades vulneráveis;
- Criar laboratórios Linux de baixo custo.

<br>

# 💻 <a id="pre-requisitos"/>Pré-requisitos

Antes de iniciar o procedimento:

1. Utilize um computador com Linux;
2. Utilize um SD Card confiável;
3. Utilize fonte de alimentação estável;
4. Não desligue a TV Box durante a instalação;
5. Utilize monitor HDMI, teclado e mouse;
6. Faça backup de arquivos importantes, se necessário.

## 🧠 Sobre o Processo

O processo oficial de descaracterização do sistema Unboxing é totalmente realizado em ambiente Linux.

O método utiliza:

<ul>
  <li>Imagem compactada <code>.img.xz</code>;</li>
  <li>Script automatizado <code>unboxing-sdcard.sh</code>;</li>
  <li>Boot via SD Card;</li>
  <li>Instalação automatizada na eMMC;</li>
  <li>Script automatizado <code>unboxing-install.sh</code>.</li>
</ul>

<br>

## ✅ Vantagens do Método

<ul>
  <li>Maior compatibilidade;</li>
  <li>Instalação simplificada;</li>
  <li>Padronização do processo;</li>
  <li>Maior estabilidade;</li>
  <li>Fluxo totalmente automatizado;</li>
  <li>Ideal para implantação em larga escala.</li>
</ul>

<br>

# 📥 Etapa 1 — Download dos Arquivos

Baixe os seguintes arquivos:

- Imagem do sistema Unboxing:

```text
www.exemplo.com.br
```

- Script de gravação:

```text
unboxing-sdcard.sh
```

<br>

# 💽 Etapa 2 — Preparando o SD Card

1. Coloque o SD Card no computador Linux;

2. Abra o terminal utilizando:

```bash
Ctrl + Alt + T
```

3. Dê permissão de execução ao script:

```bash
sudo chmod +x unboxing-sdcard.sh
```

4. Execute o script informando o caminho da imagem:

```bash
sudo ./unboxing-sdcard.sh caminho/para/imagem.img.xz
```

Exemplo:

```bash
sudo ./unboxing-sdcard.sh unboxing-ifpb-dev-1.0-h313-mxqpro.img.xz
```

> ⚠️ Durante a execução do script, tome muito cuidado ao selecionar o dispositivo correto do SD Card. Todo o conteúdo do dispositivo escolhido será apagado automaticamente.

<br>

# 📺 Etapa 3 — Inicializando a TV Box

1. Remova o SD Card do computador;
2. Insira o SD Card na TV Box;
3. Conecte:
   - HDMI;
   - Mouse;
   - Teclado;
   - Fonte de alimentação;
4. Ligue a TV Box;
5. Aguarde a inicialização do sistema.

<br>

# ⚙️ Etapa 4 — Instalação Automática do Sistema

Após o sistema iniciar:

1. Abra o terminal utilizando:

```bash
Ctrl + Alt + T
```

2. Execute:

```bash
sudo ./unboxing-install.sh
```

3. Aguarde a instalação automática.

O sistema realizará:

- Instalação completa na eMMC;
- Configuração automática do sistema;
- Ajustes finais do ambiente;
- Desligamento automático da TV Box.

<br>

# 🔌 Etapa 5 — Finalização

Após a TV Box desligar:

1. Desplugue o cabo de energia;
2. Remova o SD Card;
3. Reconecte o cabo de energia;
4. Ligue novamente a TV Box.

<br>

# ❤️ Bem-vindo ao Unboxing!

O sistema foi instalado com sucesso.
