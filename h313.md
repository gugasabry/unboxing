## 🧠 Sobre este modelo

As novas TV Boxes recebidas pelo projeto utilizam o processador <b>Allwinner H313</b>, baseado em arquitetura ARM Cortex-A53 64 bits.

Diferentemente do modelo RK322x NAND, o fluxo H313 utiliza:

<ul>
  <li>Utilização do linux para criar o SD Card;</li>
  <li>Boot Live via SD Card;</li>
  <li>Imagem compactada <code>.img.xz</code>;</li>
  <li>Script automatizado <code>unboxing-sdcard.sh</code>;</li>
  <li>Instalação automatizada via <code>unboxing-install.sh</code>;</li>
  <li>Clonagem RAW da imagem do sistema diretamente na eMMC.</li>
</ul>

<br>

## 📥 Fluxo de Replicação

```text
Imagem Mestre (.img.xz)
        ↓
      Linux
        ↓
unboxing-sdcard.sh
        ↓
  SD Card Bootável
        ↓
    Boot Live
        ↓
unboxing-install.sh
        ↓
   Clonagem RAW
        ↓
      eMMC
```

# 💽 Etapa 2 — Preparando o SD Card

1. Insira o SD Card no computador Linux;

2. Abra o terminal:

```bash
Ctrl + Alt + T
```

3. Dê permissão ao script:

```bash
sudo chmod +x unboxing-sdcard.sh
```

4. Execute:

```bash
sudo ./unboxing-sdcard.sh caminho/para/imagem.img.xz
```

### Exemplo

```bash
sudo ./unboxing-sdcard.sh unboxing-ifpb-dev-1.0-h313-mxqpro.img.xz
```

> ⚠️ Todo o conteúdo do SD Card será apagado. Escolha o caminho correto: /dev/...

<br>

# 📺 Etapa 3 — Inicializando a TV Box

1. Insira o SD Card na TV Box;
2. Conecte HDMI, mouse, teclado e fonte;
3. Ligue a TV Box;
4. Aguarde a inicialização.

<br>

# ⚙️ Etapa 4 — Instalação Automática

Abra o terminal:

```bash
Ctrl + Alt + T
```

Execute:

```bash
sudo ./unboxing-install.sh
```

O sistema realizará automaticamente:

- Instalação na eMMC;
- Configuração do sistema;
- Ajustes finais;
- Desligamento automático.

<br>

# 🔌 Etapa 5 — Finalização

1. Desplugue o cabo de energia;
2. Remova o SD Card;
3. Reconecte a energia;
4. Ligue novamente a TV Box.
